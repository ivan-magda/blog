Read this index at session start. These notes hold durable decisions and routes;
source code and accepted specifications remain authoritative.

## Maintenance

Update the relevant shared topic when a durable decision changes; update this index
when adding or removing topics. Prefer links to maintained code, documentation, and
skills over copies of their contracts. Distinguish observed implementation from old
plans and external service status, and date claims that can go stale. Keep personal
profiles, credentials, operational identifiers, and raw transcripts out of shared
notes. Never recreate or write to agent-private project memory.
